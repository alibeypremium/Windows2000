To copy counter data between instances of System Monitor

  1. Open Performance.
  2. In the System Monitor details pane, click the button on the toolbar.

    This copies all current properties in HTML format to the Windows Clipboard.

  3. Open another instance of System Monitor and click the button on the toolbar to load the counter path data from the Clipboard into the current window.

Note

  • To open Performance, click Start, point to Programs, point to Administrative Tools, and then click Performance.
