To type and format text

  1. In the toolbox, click .
  2. To create a text frame, hold down the left mouse button and drag the pointer diagonally to the size you want.
  3. On the text toolbar, click the font, size, and style you want for the text.
  4. Click inside the text frame to type text.

Notes

  • You can enter text in a text box only once. After you click outside the box, you cannot make it active again.
  • After you have created a text box, you can view the text toolbar by clicking the View menu and then clicking Text Toolbar. You can drag the toolbar to any location in the window.
  • Click to use the opaque background, in which the color of the text is defined by the foreground color, or line color, and the background is defined by the background color.
  • Click in the toolbox to insert the text on a transparent background.
  • You can enter text into a picture only in Normal view.
  • Click a color to change the color of the text.
  • Click in the toolbox to insert the text on a colored background. Then right-click in the color box to change the background color.
  • When the text tool is selected, you can paste text only. You cannot paste graphics.
