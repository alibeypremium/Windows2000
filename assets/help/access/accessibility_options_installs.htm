Accessibility wizard overview

The Accessibility wizard guides you through customizing your computer with tools designed to help you meet your vision, hearing, or mobility needs. Once the Accessibility tools are set up, they can be accessed through Control Panel and the Accessibility menu.

Open Accessibility wizard.

Notes

  • To open Accessibility wizard, click Start, point to Programs, point to Accessories, point to Accessibility, and then click Accessibility Wizard.
  • The Accessibility tools that ship with Windows 2000 are intended to provide a minimum level of functionality for users with special needs. Most users with disabilities will need utility programs with higher functionality for daily use. For a list of Windows-based accessibility utilities, see Microsoft Accessibility at the Microsoft Web site (http://www.microsoft.com/).
