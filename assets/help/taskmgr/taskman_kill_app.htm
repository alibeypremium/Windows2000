To end a program with Task Manager

  1. On the Applications tab, click the task that you want to end.
  2. Click End Task.

Notes

  • If a program stops responding, press CTRL+ALT+DELETE to start Task Manager, click the Applications tab, click the program that is not responding, and then click End Task.
  • Any data entered or changes made in that program and not saved, will be lost.
