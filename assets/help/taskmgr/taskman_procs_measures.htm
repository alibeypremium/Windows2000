Process counters

In the Task Manager Processes tab, you can monitor running processes using the following counters, which can be displayed as column headings.

  • Base Priority
  • CPU Time
  • CPU Usage
  • GDI Objects
  • Handle Count
  • Image Name
  • I/O Other
  • I/O Other Bytes
  • I/O Reads
  • I/O Read Bytes
  • I/O Writes
  • I/O Write Bytes
  • Memory Usage
  • Memory Usage Delta
  • Non-paged Pool
  • Page Faults
  • Page Faults Delta
  • Paged Pool
  • Peak Memory Usage
  • PID (Process Identifier)
  • Session ID
  • Thread Count
  • User Name
  • USER Objects
  • Virtual Memory Size
