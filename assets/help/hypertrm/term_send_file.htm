To send a file to a remote computer

  1. On the Transfer menu, click Send File.
  2. In the Filename box, type the path and name of the file you want to send.
  3. In the Protocol list, click the protocol your computer is using to send the file.
  4. Click Send.

Notes

  • To send a text file to a remote computer, on the Transfer menu, click Send Text File.
  • In most cases, you need to configure the file-transfer software on the remote computer so that it receives the file correctly. For more information, contact the administrator of the remote computer.
