Common tasks

The following tasks are frequently performed when you use HyperTerminal.

Set up a new connection

Establishing a new connection involves naming the connection, entering information about the phone number, and setting the dialing properties.

Call a remote computer

After setting up a connection to another computer, call the remote computer using the connection.

Send a file to a remote computer

Transfer files to a connected computer using a protocol you specify.

Receive a file from remote computer

Download a file from another computer using the protocol of the remote computer.

Change the settings for making a call

Use HyperTerminal to change your modem configuration, modify the phone number or network address for a connection, or to specify Minitel terminal emulation.
