To paste a multimedia file into a document

  1. On the File menu, click Open, and then double-click the file you want to copy.
  2. On the Edit menu, click Options, and then specify the options you want.
  3. On the Edit menu, click Copy Object.
  4. Open the document you want to copy the file to, and then click where you want it to appear.
  5. On the Edit menu, click Paste.

Note

  • After a file is copied into a document, you can play it from within the document by double-clicking its icon or frame.
