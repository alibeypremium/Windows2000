To specify settings for multimedia files within a document

  1. On the File menu of your program, click Open, and then double-click the document containing the multimedia file.
  2. In the document, click the multimedia file to select it.
  3. On the Edit menu, point to Media Clip Object, Video Clip Object, or MIDI Sequence Object and then click Edit.
  4. On the Edit menu, click Options, and then click the options you want.
