To change the printing priority of documents waiting to print

  4. On the General tab, drag the Priority slider to raise or lower the document priority.

Notes

  • You can change the printing priority of documents waiting to print only if you have the Manage Documents permission. For information about printing security permissions, see Related Topics.
  • Once a document has started printing, any printing priority changes you make will not affect the document.
