To view documents waiting to print

  2. Double-click the printer for which you want to view the documents waiting to print.

Notes

  • The print queue shows information about a document such as print status, owner, and number of pages to be printed. From the print queue, you can cancel or pause printing for any documents you have sent to the printer.
  • You can also open the print queue for the printer on which you are printing by double-clicking the printer icon in the status area on the taskbar.
