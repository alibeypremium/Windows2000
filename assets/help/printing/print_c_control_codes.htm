Using printer control codes

A printer control code (or control sequence) is one or more characters that a computer program sends to a printer to initiate an action, such as moving the cursor to the beginning of a new line. Control codes are often used when a program does not support the printer you are using or does not support one of its specialized features.

The following table lists the hexadecimal values of some common control codes:

To enter this Type this (including the brackets)
TAB <09>
Carriage Return <0D>
ESC <1B>
Form Feed <0C>
Line Feed <0A>
NUL <00>

You can install a generic text printer from Printers by clicking Start, pointing to Settings, and then clicking Printers.

To determine if your printer supports the use of control codes, see your printer's operating manual.
