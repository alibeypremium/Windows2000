To change the parallel port timeout settings

  3. On the Ports tab, click the LPT port that the printer uses, and then click Configure Port.
  4. Type the new number for the timeout setting in Transmission Retry.

Notes

  • To change device settings, you must have the Manage Printers permission. For information about printing security permissions, see Related Topics.
  • If you are printing to a pen plotter, you might need to increase the port timeout setting to allow more time for the plotter to clear its buffer.
  • If you print to more than one parallel port, change Transmission Retry for each port.
