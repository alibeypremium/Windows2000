To delete a port

  1. Open Printers.
  2. On the File menu, click Server Properties, and then click the Ports tab.
  3. In Ports on this server, click the port you want to delete, and then click Delete Port.
  4. Click Yes to confirm.

Notes

  • Deleting a port removes it from the available port list. Any printer that communicates through that port is disconnected.
