To install new or updated printer drivers

  3. On the Advanced tab, click New Driver to install a new or updated version of the printer driver using the Add Printer Driver wizard.
  4. Click Next, and then do one of the following:
    • Click the appropriate printer manufacturer and printer model if the new or updated driver is on the list.
    • Click Have Disk if the printer driver is not included in the list or if you have received a new or updated driver on CD or diskette from the printer manufacturer, type the path where the driver is located, and then click OK.
  5. Click Next, and then follow the instructions on the screen to finish installing the printer driver.

Notes

  • To install new or updated printer drivers, you must be logged on to your computer as a member of the Administrators group. When using Windows 2000 Professional, you may be able to install new or updated printer drivers when logged on as a member of the Power Users group, depending on the components required by the printer driver.
  • If the printer driver you want to use already exists on the print server, you can install it by selecting it from the Driver list.
  • For information about updating printer drivers and other system files using Windows Update, see Related Topics.
