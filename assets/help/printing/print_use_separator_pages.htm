To choose a separator page

  3. On the Advanced tab, click Separator Page.
  4. Click Browse and find your systemroot\System32 folder.
  5. Specify one of the separator page files that Windows 2000 provides in the System32 folder:
    • Pcl.sep, which prints a page after switching the printer to PCL printing.
    • Sysprint.sep, which prints a page after switching the printer to PostScript printing.
    • Pscript.sep, which does not print a page after switching the printer to Postscript printing.

Notes

  • To set up separator pages, you must have the Manage Printers permission. For information about printing security permissions, see Related Topics.
