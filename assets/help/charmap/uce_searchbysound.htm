To search for a Chinese, Japanese, or Korean character by the way it sounds

  1. Select the Advanced view check box.
  2. In the Group by list, click the group you want to use for the search.
  3. In the Group By dialog box, click the character that corresponds to the sound you want to search for.

    Character Map displays the characters that start with the sound you selected.

Notes

  • You can search for a character by the way it sounds in the following character sets: Japanese Kanji by Hiragana, Korean Hanja by Hangul, Simplified Chinese by PinYin, Traditional Chinese by Bopomoto.
  • If the list of character sets in the Group By list does not include the character sets named in the previous note, you can add these character sets using Control Panel, if you are logged on as an Administrator. First, in Control Panel, double-click Regional Options. Then, under Language settings for the system, click to select the languages you want to add.
