To search for a character by name

  1. In the Font list, click the font you want to search.
  2. Select the Advanced view check box.
  3. In the Character set list, click the character set you want to search. If a character set is not available, choose a different font.
  4. In the Search for box, type all or part of the name of the character you are searching for.
  5. Click Search.

Notes

  • To start another search, click Reset.
  • To view the name of a particular character (and its associated hexadecimal code), position your pointer over the character.
  • To search for a character by name in a specific Unicode category, click Unicode Subrange in the Group by box. For more information, see Related Topics.
