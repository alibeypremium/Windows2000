To view a caller on video

  1. Click the Edit menu, and then click Options.
  2. Click the Audio/Video tab.
  3. Under Line, select the type of call you want to set options for.
  4. Make sure Video Playback is checked.
  5. Repeat step 3 and 4 for each type of call for which you want to view the caller.

Note

  • Uncheck Video Playback for each type of call for which you do not want to view the recipient.
