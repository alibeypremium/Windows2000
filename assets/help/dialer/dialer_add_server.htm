To connect to an Internet directory

  1. Click the Edit menu, and then click Add Directory.
  2. In the Add Directory Server dialog box, type the name of the server, and then click Add.

Notes

  • An Internet directory links your computer to a server on the Internet. For example, you can set up a directory to link to an external company's server and have access to all users in that database.
  • The Directory Name list shows any server published on your network as set up by the network administrator. This same list of servers is displayed by default under My Network Directory.
  • To see a list of all the scheduled conference calls on the Internet directory, click the server name in the Directories pane on the left, and then double-click Conferences. The conferences are listed in the right pane.
  • To see the most recent list of all of the scheduled conference calls, click the View menu, and then click Refresh.
