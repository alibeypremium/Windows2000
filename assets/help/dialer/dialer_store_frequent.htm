To add names to your speed-dial list

  1. Click the Edit menu, and then click Add to Speed Dial List.
  2. Under Display Name, type the name for this speed-dial entry.
  3. Under Number or Address, type the telephone number, IP address, or DNS (Domain Name System) name for the person you're adding.
  4. Under Dial As, do one of the following:
    • Click Phone Call to place the call over a telephone line.
    • Click Internet Call to place the call using a network connection.
    • Click Internet Conference to place the call using a specific internet connection.

Notes

  • To edit all of your stored numbers at once, click the Edit menu, click Speed Dial List, and then click Edit.
  • To add numbers to your speed dial list, right-click the name of the person in the Peoples folder, and then click Add to Speed Dial List.
  • You can also add a number to the speed-dial list as the number is dialing. In the active call window, click the Add to Speed Dial icon ().
