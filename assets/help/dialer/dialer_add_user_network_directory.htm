To add a user to your network directory

  1. Click My Network Directory.
  2. Click the Edit menu, and then click Add User.
  3. In the Add User dialog box, type the name or partial name of the person you are adding, and then click Search.
  4. Click the name of the user you want to add to your directory, and then click Add.

Notes

  • Adding people to your network directory allows you to easily dial those people without having to search the domain server each time.
  • The Search option searches the domain server that lists all people logged on to your network's directory. The user you are adding must exist in this directory in order to add it to your network directory.
  • Search is unavailable if you have not typed a name or partial name under User.
