To change fonts in Help

  1. Click Start, point to Programs, and then click Internet Explorer.
  2. On the Tools menu, click Internet Options.
  3. On the General tab, click Fonts.
  4. In the Fonts dialog box, select the options you want, and then click OK.
  5. On the General tab, click Accessibility.
  6. Under Formatting, select the check boxes for the options you want, and then click OK.

Notes

  • This procedure changes the fonts only in the topic pane of the Help Viewer, not in the navigation pane, which contains the Contents, Index, Search, and Favorites tabs. To change the fonts in the navigation pane, see Related Topics.
  • This procedure also changes the fonts used to display Web pages in Internet Explorer.
