To bookmark a Help topic

  1. Use the Contents, Index, or Search tab to locate and then display the topic you want to bookmark.
  2. Click the Favorites tab, and then click Add.

    3. The Help Viewer adds the topic title to the Topics list. Later, you can return to this list and double-click the bookmark to quickly display the topic.

Notes

  • You can create a list of favorite/frequently visited Help topics.
  • To remove a bookmark from the Topics list, click the bookmark, and then click Remove.
  • If you display an externally linked topic (not part of the current Help file) and bookmark it, the Help Viewer adds a link to the topic, instead of the topic's title, to the Topics list.
  • For information on how to locate a Help topic, see Related Topics.
  • The Favorites tab is only available in the main Windows Help file, which you access by clicking Start and then clicking Help.
