To select the font for On-Screen Keyboard keys

  2. On the Settings menu, choose Font.
  3. In the Font dialog box, select a font, font style, and font size.

Notes

  • If you are using another language, it may be necessary to change font options to see additional foreign language characters.
  • The selected font options only affect the appearance of the On-Screen Keyboard keys and not the font used in the selected program.
