To select a keyboard layout

  2. On the Keyboard menu, select the following keyboard options:
    • To select the keyboard layout, choose Enhanced Keyboard which includes the numeric keypad, or Standard Keyboard which displays a keyboard without the numeric keypad.
    • To select the way the keys appear on the keyboard, choose Regular Layout which displays the keys as they would normally appear on a standard keyboard. To display the most frequently used character keys together on the keyboard, choose Block Layout. Block layout also puts the directional arrow keys in the lower right corner.
    • To select the U.S. standard keyboard choose 101 keys, for the universal keyboard choose 102 keys, and for the keyboard with additional Japanese characters choose 106 keys.

Notes

  • Block layout is especially useful if you are using Hover to select mode as the characters most used are easy to select.
  • The 102 keys and 106 keys settings are not available with Block Layout.
