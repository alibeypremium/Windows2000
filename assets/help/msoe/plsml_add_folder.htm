To add, delete, or switch folders
  • To add a folder, click the File menu, point to Folder, and then click New. In the Folder name text box, type the name, and then select the location for the new folder.
  • To delete a folder, click the folder in the Folders list. Then click the File menu, point to Folder, and click Delete.
  • To switch to another folder, click the folder in the Folders list.
Note
  • You cannot delete or rename the Inbox, Outbox, Sent Items, Deleted Items, or Drafts folders.
