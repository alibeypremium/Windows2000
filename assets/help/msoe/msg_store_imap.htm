To configure the path to your mailbox on an IMAP server

  1. On the Tools menu, click Accounts.

  2. Select your IMAP server from the Accounts list.

  3. Click Properties, and then click the IMAP tab.

  4. Type the path in the Root Folder Path box.

    The root folder path identifies the mailbox that contains your folders on the server. Do not end the root folder path with a hierarchy character. For example, ~username/Mail is a valid root folder path, but ~username/Mail/ is not. If you are not sure what to type here, leave this box blank.

Note
  • If your IMAP server is a Cyrus server, your user folders must be contained in the Inbox folder. If your IMAP server is UNIX-based, your mail is usually stored in its own directory in your user home directory—for example: ~username/Mail.
