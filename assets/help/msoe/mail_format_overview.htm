Formatting message text

When you want to add special emphasis or structure to message text—such as bold, color, or bulleted lists—you can use Hypertext Markup Language (HTML), the standard for formatting text for the Internet. Using HTML formatting also enables you to add graphics and links to Web sites in your messages.

When you use HTML formatting and the recipient's mail or news program does not read HTML, the message appears as plain text with an HTML file attached. Only e-mail programs that support MIME (Multipurpose Internet Mail Extensions) can read HTML formatting.
