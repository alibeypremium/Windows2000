To use revocation checking

When revocation checking is turned on, the digital IDs of secure messages you receive are checked when you open them (as long as you are online). A message is automatically sent to the certification authority requesting information on the digital ID used for the message.

  1. On the Tools menu, click Options.

  2. On the Security tab, click Advanced.

  3. Click Only when online if you want digitally signed messages to be checked. You have to already be online to use this feature.
