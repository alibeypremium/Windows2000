To delete a message from an HTTP mail account
  1. In the Folders list, select your HTTP account (for example, your Hotmail account).

  2. In the message list, select the message (or messages) you want to delete.

  3. On the toolbar, click the Delete button.

    This moves the message to the Deleted Items folder.

Notes
  • Your HTTP mail server may not allow you to empty the Deleted Items folder for your HTTP mail account yourself, as you can with POP3 accounts.

  • Some HTTP mail servers, such as Hotmail, automatically empty the Deleted Items folder regularly on their own schedule.
