To read your messages

After Outlook Express downloads your messages, or after you click the Send/Recv button on the toolbar, you can read messages either in a separate window or in the preview pane.

  1. Click the Inbox icon on either the Outlook bar or the Folders list.

  2. To view the message in the preview pane, click the message in the message list.

    To view the message in a separate window, double-click the message in the message list.

Tips
  • To view all the information about a message, such as when it was sent, click the File menu, and then click Properties.

  • To save the message in your file system, click Save as and then select a format (mail, text or HTML) and location.
