Exporting items from Outlook Express

You can export items in Outlook Express to use in other programs, including Microsoft programs as well as other software programs. These items include:

  • Address Book. You can export your address book from Outlook Express so that it can be used in other Microsoft mail programs, such as Outlook.

  • Messages. You can export messages in one or more of your folders
