To set up Outlook Express to use multiple certificates

You can set up Outlook Express to send digitally signed messages using one certificate and use another certificate to send encrypted messages. You must obtain at least one certificate before proceeding. See Related Topics below.

  1. On the Tools menu, click Accounts.

  2. Select the account you want to use the certificate with, and then click Properties.

  3. On the Security tab, click Select for the type of certificate you want to use.
