To use Outlook Express to complete an e-mail address
  1. In a new message window, type a partial name or address in the To box.

  2. On the Tools menu, click Check Names.
Tip
  • To set up Outlook Express to automatically check names, on the Tools menu, click Options, and then select the Send tab. Select Automatically complete e-mail addresses when composing.
