To delete a message from an IMAP account
  1. In the message list, select the message.

  2. On the toolbar, click the Delete button. This marks the message you want to delete.

  3. On the Edit menu, click Purge Deleted Messages to remove the deleted items from the folder. Once you purge a message, it cannot be undeleted.

Notes
  • To restore a message that is marked for deletion on an IMAP server, click the Edit menu, and then click Undelete.

  • To automatically purge deleted messages, on the Tools menu, click Options. On the Maintenance tab, select Purge deleted messages when leaving IMAP folders.

    You must be connected for the deletions to occur; if you are not connected, the purged messages will be deleted the next time you connect.
