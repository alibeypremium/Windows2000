To customize the toolbar
  1. If you are in the main window, on the View menu, click Layout, and click Customize Toolbar.

    If you are in a message window, then on the View menu, point to Toolbars, and then click Customize.

  2. To modify the toolbar text, select from the Text Options list.

  3. To modify the icon size, select from the Icon Options list.

  4. To add or remove buttons, click the button name in the Available toolbar buttons list, and then click Add or Remove.

    To change the order in which buttons appear, click the button in the Current toolbar buttons list, and then click Move Up or Move Down.
