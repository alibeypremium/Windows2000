To read messages while you are away from your Internet connection
  1. On the Tools menu, select Options.

  2. On the General tab, find the field labeled If my computer is not connected at this time, and then select Connect only when not working offline.

  3. If you connect to an IMAP or http server, click the server name in the folder list, make sure that the items you want to view offline are checked, and then click Sync Account.

  4. On the File menu, click Work Offline.
Note

  • To check the type of account you have, click the Tools menu, and then click Accounts. Select your e-mail account and then click Properties. The account type is listed on the Advanced tab.
