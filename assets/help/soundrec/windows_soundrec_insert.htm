To insert a sound file into a document

  1. On the File menu, click Open, locate the sound file you want to insert, and then double-click it.
  2. On the Edit menu, click Copy.
  3. Using a word processing program such as WordPad, open the document into which you want to copy the sound, and then click where you want to insert the sound.
  4. On the Edit menu, click Paste.

Notes

  • You can also link a sound file to a document.
  • Recorded sounds are saved as waveform (.wav) files.
