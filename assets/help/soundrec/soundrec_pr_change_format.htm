To change the format of a sound file

  1. On the File menu, click Open, locate the sound file you want to modify, and then double-click it.
  2. On the File menu, click Save As, and then click Change.
  3. Click an audio format in the Name list.

Notes

  • You can also add your own format to the Name list by changing the values under Format and Attributes, and then clicking Save As.
  • Sound Recorder uses waveform (.wav) files.
