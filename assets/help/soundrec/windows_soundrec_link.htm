To link a sound file to a document

  1. On the File menu, click Open, locate the sound file you want to link, and then double-click it.
  2. On the Edit menu, click Copy.
  3. Using a word processing program such as WordPad, open the document in which you want to link the sound, and then click where you want to insert the sound.
  4. On the Edit menu, click Paste Special.
  5. Click Paste Link and then click OK.

Notes

  • If the Edit menu does not contain Paste Special, your program does not support linking.
  • Sound Recorder uses waveform (.wav) files.
