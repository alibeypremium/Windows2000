To delete part of a sound file

  1. On the File menu, click Open, locate the sound file you want to modify, and then double-click it.
  2. Move the slider to the place in the file that you want to cut.
  3. On the Edit menu, click Delete Before Current Position or Delete After Current Position.

Notes

  • Until you save the file, you can undo a deletion by clicking the File menu, and then clicking Revert.
  • Recorded sounds are saved as waveform (.wav) files.
