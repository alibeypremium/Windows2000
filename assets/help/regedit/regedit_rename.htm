To rename a key or value

  1. Click the registry key or value entry you want to rename.
  2. On the Edit menu, click Rename.
  3. Type the new name, and then press ENTER.

Notes

  • If you make a mistake that results in your computer not starting properly, you can restore the registry. For information, see Related Topics.
  • You cannot rename the root keys or the default value of a key.
