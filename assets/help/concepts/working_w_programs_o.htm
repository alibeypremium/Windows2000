Working with programs overview

Understanding some of the fundamental skills needed when using programs in Windows 2000 helps you quickly accomplish tasks and improve overall efficiency. As you understand how programs carry out commands and communicate with other programs, you are able to perform several tasks at once and share information between programs.

Use Add/Remove Programs to easily add new programs or remove old ones that are taking up necessary space. Once installed, there are several ways to start programs, and you can store shortcuts to programs in convenient locations.

Program windows are very easy to arrange, resize, and move around your screen. You can copy and paste information from one program to another, or link information so that when you update the file in one program the information is also updated in the linked program. Windows 2000 also makes it easy to use your computer to perform tasks in several programs simultaneously.
