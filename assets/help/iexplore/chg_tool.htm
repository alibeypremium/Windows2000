To change the appearance of the toolbar

  • You can add or remove standard toolbar buttons, use smaller toolbar buttons like the ones used in Microsoft Office, and change the order they are displayed on the toolbar. Just right-click the toolbar, and then click Customize.
  • You can move or resize the Address bar, Links bar, and radio bar by dragging them up, down, left, or right. You can even move them into the menu bar!
  • You can hide the Address bar, Links bar, or radio bar by right-clicking the toolbar and then clicking to clear the check mark for each item you want to hide.
  • You can add items to the Links bar by dragging the icon from the Address bar or dragging a link from a Web page.
  • You can rearrange items on the Links bar by dragging them to a new location on the bar.

Note

  • The radio toolbar is available in Internet Explorer when you install Windows Media Player.
