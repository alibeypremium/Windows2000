To display a channel on the desktop

Note

  • The desktop Channel bar is available only if you have upgraded from Internet Explorer 4.0 or Windows 98.

  1. Right-click the desktop, and then click Properties.
  2. On the Web tab, select the View my Active Desktop as a Web page check box.
  3. If you want to use a channel you've already installed, select it from the list, and then click OK.

    If you want to choose a new channel, click New, and proceed to step 4.

  4. If you want to open the Windows Media Showcase site and choose a new channel from there, click Yes. If you click Yes, the dialog box closes and you connect to the Web.

    If you want to select a channel from another location, click No, and proceed to step 5.

  5. Type the address for the channel, or click Browse to search for it.
