To access FTP sites through a CERN-compliant proxy server

  1. In the Address bar, type the Internet address (URL) for the FTP site you want to connect to. For example:
    ftp://ftp.microsoft.com/

    If the site requires a username and password, you need to include that information in the address. For example:
    ftp://username:password@ftp.microsoft.com/

  2. To download a file or folder, right-click the item on the page, and then click Download To.

Note

  • If your system uses a CERN proxy server, you will only be able to download and view files. Check with your administrator to see whether you can bypass the proxy server or whether a full-service FTP proxy server is available.
