To specify the programs you want Internet Explorer to use

You can change the default programs you use for mail, newsgroups, calendar, and Internet calls. Whenever you click a link on a Web page for these programs, Internet Explorer opens the program you specified.

  1. On the Tools menu in Internet Explorer, click Internet Options.
  2. Click the Programs tab, and then follow the instructions on your screen for specifying default Internet programs.

Tips

  • To start another Internet program from within Internet Explorer, click the Tools menu, point to Mail & News, and then click a command.
  • To send messages and place calls from within Internet Explorer, click the File menu, point to New, and then click the type of message or communication you want to start.
