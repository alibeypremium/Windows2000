To display the Channel bar on the desktop

Note

  • The desktop Channel bar is available only if you have upgraded from Internet Explorer 4.0 or Windows 98.

You can use the Channel bar to quickly open Web channels from your desktop without first opening the browser. You can display the Channel bar on your desktop whether or not you are running the Active Desktop.

If you installed the browser without the new desktop

  • Click the Start menu, point to Programs, point to Internet Explorer, and then click Channel Bar.

If you installed the browser with the new desktop

  1. Right-click the desktop, and then click Properties.
  2. On the Web tab, select the View my Active Desktop as a Web page check box.
  3. Select the Internet Explorer Channel Bar check box.

Tip

  • To close the Channel bar, point to the top of the Channel bar, and then click the Close button that appears.
