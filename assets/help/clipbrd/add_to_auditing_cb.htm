To add a group or user to the auditing list

  1. In the Local ClipBook window, click the ClipBook page you want to audit.
  2. On the Security menu, click Auditing.
  3. In the ClipBook Page Auditing dialog box, click Add.
  4. If necessary, display the names of groups and users:
    • To see the names of users on a selected computer or domain, click Show Users.
    • To see the contents of a selected local or global group, click Members. To add the members to the auditing list, click the names in the Local Group Membership or Global Group Membership dialog box, and then click Add.
  5. In the Names list, click the groups or users you want to add to the auditing list, and then click Add.

Notes

  • To add a user or group to the auditing list for a ClipBook page, you must be logged on as a member of the Administrators group.
  • The Add Users and Groups dialog box displays the groups on the computer or in the domain that appears in the List Names From list. Local groups are followed by an asterisk (*). To view the groups in another domain, click the domain name in the List Names From list.
  • If you don't know the domain of the user or group, click Search in the Add Users and Groups dialog box.
  • If you don't want to wait for Windows 2000 to list the groups in the Names list, you can type the name in the Add Names box.
  • Domains appear only if your computer is a member of a domain on a Windows 2000 Server network. The domains shown have a trust relationship with the domain containing the page.
