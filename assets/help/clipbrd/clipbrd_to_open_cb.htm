To open a Clipboard file

  1. In ClipBook Viewer, click the Clipboard window.
  2. On the File menu, click Open.
  3. In the File name box, type the name of the Clipboard file you want to open. If there is already information on the Clipboard, a confirmation message asks if you want to clear this information from the Clipboard. Click Yes to clear the contents from the Clipboard and open the file you specified.
