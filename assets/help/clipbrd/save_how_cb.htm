To save the contents of the Clipboard to the local ClipBook

  1. In ClipBook Viewer, click the Local ClipBook window.
  2. On the Edit menu, click Paste.
  3. In the Page Name box, type a name for the ClipBook page.
  4. To make this page available for others to use, select the Share Item Now check box, and then click OK.
  5. In the Share ClipBook Page dialog box, select the sharing options you need.

Note

  • If the Paste command is not available, first select information in a file and copy it. You can then paste the information into ClipBook Viewer. When you select and then cut or copy information, it is placed in a temporary storage location called the Clipboard.
