To audit a ClipBook page

  1. In the Local ClipBook window, click the ClipBook page you want to audit.
  2. On the Security menu, click Auditing.
  3. In the Name list, click the name of the group or user.
  4. Under Events to Audit, select the events to audit.

Notes

  • You must be logged on as an administrator or a member of the Administrators group in order to complete this procedure. If your computer is connected to a network, network policy settings may also prevent you from completing this procedure.
  • You must have auditing set up in Group Policy. For more information, see Related Topics.
  • If the Name list does not contain entries, you must add a group or user to the auditing list. For more information, see Related Topics.
