To share a local ClipBook page

  1. In the local ClipBook window, click the ClipBook page you want to share.
  2. On the File menu, click Share.
  3. In the Share ClipBook Page dialog box, do one of the following.
    • To start the program used to create the page contents whenever a user attempts to link the page to a document, select the Start Application on Connect check box.
    • To run the program as a minimized icon, select both the Start Application on Connect and Run Minimized check boxes.
  4. To control the access that groups and individual users have to the page, click Permissions.

Notes

  • To change the settings on a shared ClipBook page, click the page, and then on the File menu, click Share. The ClipBook Page Properties dialog box appears, where you can change the settings to suit your needs.
  • Clipboard files cannot be shared. To share the contents of your Clipboard with someone else, you must save it as a ClipBook page in your Local ClipBook.
