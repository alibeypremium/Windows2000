To change permissions for a shared ClipBook page

  1. In the Local ClipBook window, click the ClipBook page you want to change permissions for.
  2. On the Security menu, click Permissions.
  3. In the Name list, click the name of the group or user whose permissions you want to change.
  4. In the Type of Access list, click a different permission type.

Note

  • To change permissions for a shared ClipBook page, you must be the owner of the page or have been granted permission to do so by the owner.
