To add a group or user to the ClipBook permissions list

  1. In the Local ClipBook window, click the ClipBook page you want to add permissions for.
  2. On the Security menu, click Permissions.
  3. In the ClipBook Page Permissions dialog box, click Add.
  4. If necessary, display the names of groups and users:
    • To see the names of users on a selected computer or domain, click Show Users.
    • To see the contents of a selected local or global group, click Members. To add the members to the permissions list, click the names in the Local Group Membership or Global Group Membership dialog box, and then click Add.
  5. In the Names list, click the groups or users you want to add to the permissions list, and then click Add.
  6. In the Type of Access list, click a permission type.

Notes

  • The Add Users and Groups dialog box displays the groups on the computer or the groups in the domain shown in the List Names From list. Local groups are followed by an asterisk (*). To view the groups in another domain, click the domain name in the List Names From list.
  • If you don't know the domain of the user or group, click Search in the Add Users and Groups dialog box.
  • If you don't want to wait for Windows 2000 to list the groups in the Names list, you can type the name in the Add Names box.
  • Permissions for shared ClipBook pages are cumulative. For example, if an individual user is a member of more than one group, and each group has a different set of permissions for the same shared ClipBook page, then all permissions granted to the user for that ClipBook page are available. The exception is the No Access permission, which overrides every other permission.
  • Domains appear only if your computer is a member of a domain on a Windows 2000 Server network. The domains shown have a trust relationship with the domain containing the page.
