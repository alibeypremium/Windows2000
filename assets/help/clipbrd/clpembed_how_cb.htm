To copy an object from another computer to the local Clipboard

  1. On the File menu, click Connect.
  2. In the Computer box, type the name of the computer you want to connect to, or click the name in the Select Computers list, and then click OK.
  3. Click the ClipBook page you want to copy from.
  4. On the Edit menu, click Copy.

    A copy of the information is temporarily placed on the Clipboard.
