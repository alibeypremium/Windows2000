To save the contents of the Clipboard to a file

  1. In ClipBook Viewer, click the Clipboard window.
  2. On the File menu, click Save As.
  3. In Save in, navigate to the the folder where you want to save the file.
  4. In the File name box, type a name for the file you want to save.
  5. Click Save.

Note

  • The default extension for a Clipboard file is .clp.
