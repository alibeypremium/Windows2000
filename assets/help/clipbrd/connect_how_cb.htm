To connect to a ClipBook on another computer to access shared ClipBook pages

  1. On the File menu, click Connect.
  2. In the Computer box, type the name of the computer that has the ClipBook you want to connect to, or select a name in the Select Computer list.

    The ClipBook on the remote computer opens in ClipBook Viewer on your computer and the shared ClipBook pages are available to work with.

Notes

  • If you do not see anything in the ClipBook, the owner of the ClipBook has not shared the ClipBook pages.
  • When you have finished using the other ClipBook, you can disconnect from it.
  • You must connect to a ClipBook on another computer before you can use the information in its shared pages.
