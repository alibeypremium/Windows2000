Preface

Getting Started introduces you to Microsoft Windows 2000 Professional and helps you get the operating system up and running right away. In addition to learning how to install Windows 2000, you learn how to use the desktop, and you find out about new features. This book also presents information about advanced issues, such as connecting to a network, and answers to commonly asked questions.
