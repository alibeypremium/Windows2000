Stop Error 0x0000007A

Stop error number: (0x0000007A)
Descriptive text: KERNEL_DATA_INPAGE_ERROR
Usual cause: The requested page of kernel data from the paging file could not be read into memory (usually due to a bad block in a paging file, a virus, a disk controller error, or failing RAM).

To troubleshoot Stop error 0x0000007A

  1. Using a current version of your virus-protection software, check for viruses on your computer. If you find a virus, perform the steps required to eliminate it from your computer. See your antivirus software documentation for these steps.
  2. If the computer is formatted with NTFS, restart your computer, and then run Chkdsk /f /r on the system partition. If you cannot start the system due to the error, use the Command Console and run Chkdsk /r.
  3. Run any system diagnostics supplied by your computer manufacturer, especially the memory check.
