Stop Errors 0x00000023 and 0x00000024

Stop error number: (0x00000023) or (0x00000024)
Descriptive text: FAT_FILE_SYSTEM or NTFS_FILE_SYSTEM
Usual cause: A problem occurred within Ntfs.sys (the driver file that allows the system to read and write to NTFS drives).

To troubleshoot Stop error 0x00000023 or 0x00000024

  1. Run the system diagnostics supplied by your computer manufacturer, especially hardware diagnostics.
  2. Disable or uninstall any antivirus, disk defragmentation, or backup programs.
  3. Check for hard drive corruption by running Chkdsk /f at the command prompt, and then restart the computer.
