Readme Files

Readme files are supplemental documents containing late-breaking information that was unavailable when this book and Windows 2000 Help were written. The following readme documents are stored on your Windows 2000 CD.

File Contains
Read1st.txt Preinstallation notes vital to a successful installation and information about hardware conflicts and troubleshooting.
