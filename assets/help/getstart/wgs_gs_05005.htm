Using Groups

Groups are used to grant one or more users specific permissions. Windows 2000 has built-in local groups that help the administrator efficiently assign permissions to users based on the tasks the users need to perform. You can also create your own groups.

To add a user to a local group

  1. Log on to Windows 2000 as an administrator or as a user with administrator rights.
  2. Click the Start button, point to Settings, and then click Control Panel.
  3. In Control Panel, double-click Users and Passwords.
  4. On the Users tab, click the user name, and then click Properties.
  5. Select the level of access you want to assign to the user.

    To select from a list of built-in local groups, click the Other arrow.

  6. Click OK, and then click OK again.
