Searching for Files and Folders

You can also search for computers, people, and Internet sites.

You can store files and folders in many locations—on the hard disk, a network drive, a floppy disk, and so on. To quickly locate them in any of these locations, use the Search command on the Start menu.

To search for a file or folder

  1. Click the Start button, point to Search, and then click For Files or Folders.
  2. Type the name of the file or folder for which you want to search, and then click Search Now.
