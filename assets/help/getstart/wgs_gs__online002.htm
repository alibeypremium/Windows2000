Search Tips

By using the Search tab in the left frame, you can search this book for words or combinations of words. The Search tab is useful when you're looking for instructions about something specific. For example, if you're setting up Windows from the DOS prompt, you can find helpful information if you search for topics that contain the words "setup" and "DOS."

Searching for a Word

To simply search for a word in the book, click the Search tab, type the word in the text box, and press ENTER. If the word occurs in the book, the titles of the appropriate topics appear in the box below. Click a title to view the topic in the right frame. The word for which you searched is highlighted.

Narrowing or Expanding Your Search

Searching for a single word is a very wide type of search—it can result in a large number of topics. You can limit your search, and the number of topic titles that result, by searching for different combinations of words. You can also increase the scope of your search. The following table lists the different types of searches, from widest to narrowest—from the greatest number of listed topics to the smallest number.

Search type Example Search When to Use
OR setup or installation When you want to search for topics that contain any one of a number of words. This search is especially useful if you're not sure which term has the information that you need.
NOT backup not Windows When you want a limited search for a single word. This search avoids topics in which that word is used with another specific word.
Single word backup When you want to search for all occurrences of a word
AND backup and Windows When you want to search for a combination of words.
NEAR backup near Windows When you want to search for a combination of words, but only when they're within eight words of one another.
Quotation marks "Windows Backup" When you want to search an exact phrase.

Additional Search Tips

  • You can combine search methods and further narrow your search. For example, you can search for: 
    user near setup not "control panel"
  • You can limit your search even more with the options at the bottom of the Search tab.
