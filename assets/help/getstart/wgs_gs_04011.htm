Adding and Removing Programs

You can quickly add programs, such as a word processing program or game, by using Add/Remove Programs in Control Panel.

To add or remove a program

  1. Click the Start button, point to Settings, and then click Control Panel.
  2. Double-click Add/Remove Programs.

    Add/Remove Programs opens.

  3. Click Change or Remove Programs or Add New Programs, and then follow the instructions that appear.

Note

You can also add and remove Windows components by clicking Add/Remove Windows Components in Add/Remove Programs and then following the instructions that appear.
