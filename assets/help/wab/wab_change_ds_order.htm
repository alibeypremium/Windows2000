To change the order in which directory services are checked
  1. In Outlook Express or the Address Book, click the Tools menu, and then click Accounts.

  2. If you are in Outlook Express, click the Directory Service tab.

  3. Click Set Order, select a directory service, and then click Move Up or Move Down.
