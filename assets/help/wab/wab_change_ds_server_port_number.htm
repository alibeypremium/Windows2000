To change the server port number for a directory server

Follow this procedure only if instructed to do so by a directory service administrator.

  1. In the Address Book or Outlook Express, click the Tools menu, and then click Accounts.

  2. If you are in Outlook Express, click the Directory Service tab.

  3. Click the directory service you are changing, click Properties, and then click the Advanced tab.

  4. Set the Server Port Number as instructed by your directory service administrator.
