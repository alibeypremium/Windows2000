To open the Address Book
  • To open the Address Book from Outlook Express, click the Addresses button on the toolbar, or click the Tools menu and select Address Book.

  • To open the Address Book from within a message window, click the To, Cc, or Bcc icon.

Tip
  • To use the Address Book directory services from the Windows Start menu, click the Start button, point to Find, and then click People.
