To set up a directory service to check for e-mail addresses

When you can't remember someone's complete e-mail address, you can enter a partial name and then use the Check Names command on the Tools menu to search for matches. Outlook Express first searches your address book and if no matches are found, searches the directory services you have set up to check e-mail addresses.

  1. In the Address Book or Outlook Express, click the Tools menu, and then click Accounts.

  2. If you are in Outlook Express, click the Directory Service tab.

  3. Select a directory service, and then click Properties.

  4. On the General tab, select the Check names against this server when sending mail check box.
