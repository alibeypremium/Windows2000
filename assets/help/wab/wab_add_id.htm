To add a new identity while using the Address Book

  1. On the File menu, click Switch Identity, and then click the Manage Identities button.

  2. Click New, and type the name of the new identity.

  3. Select the password requirement option and enter a password if you want to include a password for this identity.
Note
  • You can add an identity from the Address Book if you opened it from the Start menu (Start, Programs, Accessories, Address Book), but not if you opened the Address Book from Outlook Express. You can also add identities from Outlook Express.

  • You can change an identity's name or password later if you want.
