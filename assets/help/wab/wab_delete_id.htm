To delete an identity from your address book

  1. On the File menu, click Switch Identity, and then click the Manage Identities button.

  2. Select an identity, and then click Remove.

Notes
  • You cannot delete the current identity, nor can you delete the last remaining identity.

  • When you delete an identity, the corresponding settings are deleted, but the data is not.

  • The Switch Identity command in the Address Book is available only when you open it from the Start menu (Start, Programs, Accessories, Address Book).
