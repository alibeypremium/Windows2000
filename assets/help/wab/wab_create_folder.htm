To create a subfolder

  • In the Address Book, click the New button on the toolbar, and then click New Folder.

Notes
  • A new identity folder is automatically created when you create an identity in Outlook Express or any other identity-aware application. Remember that the Main Identity's Contacts and the Shared Contacts folders cannot be deleted.
