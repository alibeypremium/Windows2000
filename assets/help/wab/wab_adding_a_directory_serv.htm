To add a directory service

You will need the server name to add a directory service to your address book. You obtain this information from the directory service provider.

  1. In either the Address Book or Outlook Express, click the Tools menu, and then click Accounts.

  2. In Outlook Express, select the Directory Service tab, click Add, click Directory Service, and then follow the instructions in the Internet Directory Server Name wizard.

    In the Address Book, click Add, and follow the instructions in the Internet Directory Server Name wizard.
