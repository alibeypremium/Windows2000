To switch to a different identity

If you open your address book from the Start menu (Start, Programs, Accessories, Address Book), you can switch identities while using the address book. (If you open your address book from Outlook Express, you must switch identities in Outlook Express.)

  1. On the File menu, click Switch Identity.

  2. Select the user you want to switch to.

    Your address book starts using the new identity's settings without closing the program. In fact, Outlook Express and all other identity-aware programs that are open switch to the new identity's accounts and settings.

Note
  • If you cannot see your folder and the Shared Contacts folder in your address book, point to the View menu and select Folders and Groups.

  • Your contacts are not private. If you open your address book from the Start menu (Start, Programs, Accessories, Address Book), you can click Show All Contents to see all the contacts for every identity.
