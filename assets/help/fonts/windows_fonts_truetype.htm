To display only TrueType fonts

  1. Open Fonts in Control Panel.
  2. On the Tools menu, click Folder Options, and then click the TrueType Fonts tab.
  3. Select the Show only TrueType fonts in the programs on my computer check box.

Notes

  • TrueType is a WYSIWYG font technology, which means that the printed output is identical to what appears on the screen. Another advantage of TrueType fonts is that the characters can be scaled to any size.
