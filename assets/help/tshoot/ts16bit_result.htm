Windows 3.x Programs Troubleshooter

Windows 3.x was a 16-bit operating system. Windows 95 and later operating systems are 32-bit operating systems. To run older Windows 3.x programs, Windows 95 and later operating systems must emulate a 16-bit environment.

To determine if your program is 16-bit, consult your program documentation or contact the program manufacturer.
