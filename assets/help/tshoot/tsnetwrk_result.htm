Networking (TCP/IP) Troubleshooter

This troubleshooter can help you resolve network connection problems related to TCP/IP. Most networks, including intranets and the Internet, rely on TCP/IP to send and receive information.

Most steps in this troubleshooter involve running ping and other network commands from a command prompt. To save time, open a Command Prompt window now and keep it open for the entire troubleshooter.

To open a Command Prompt window

  • Click Start, point to Programs, point to Accessories, and then click Command Prompt.

Note for DHCP network users

  • A Dynamic Host Configuration Protocol (DHCP) network allocates and assigns Internet Protocol (IP) addresses to client computers through a centralized system. If you are using a DHCP network, you may be able to identify your network problem, but your network administrator will have to fix it.

What problem are you having?

I can't connect to another computer or Web page.
I can't ping a computer name.
I can't ping an IP address.
