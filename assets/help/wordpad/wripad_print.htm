To print a WordPad document

  1. On the File menu, click Print.
  2. On the General tab, select the printer and options you want, and then click Print.

Notes

  • You must have a default printer set in the Printers folder. For more information, see Related Topics.
  • To see how your document will look before you print it, on the File menu, click Print Preview. In Print Preview, you can click Close to return to the document.
