Common tasks

Create, open, or save a WordPad document

To create, open, and save WordPad documents, on the File menu, click New, Open, or Save.

Wrap text to the window size

The options for wrapping text affect only how text appears on your screen. When printed, the document uses the margin settings specified in the Page Setup dialog box.

Print a WordPad document
