To use keyboard controls

To Press
Move the left flipper z
Move the right flipper /
Nudge the table to the right x
Nudge the table to the left .
Nudge the table up UP ARROW
Launch the ball SPACEBAR

The following keyboard shortcuts are also helpful.

To Press
Start a new game. F2
Pause and resume the game. F3
Toggle between using the entire screen or a window for playing the game. F4
Open the 3D Pinball: Player Controls dialog box, where you can change the default game controls. F8

Notes

  • To change the keyboard controls, click the Options menu, and then click Player Controls.
  • The longer you hold down the SPACEBAR, the more powerful the launch.
  • To display the menu bar at the top of the screen when playing in Full Screen mode, press ALT.
  • Be careful not to nudge the table too much. If you do, it will tilt and the table components will stop working until the ball currently in play drains.
