Using Internet Options

You can change your Internet Explorer settings using Internet Options. You can specify the first Web page you see when you start the browser, delete temporary Internet files stored on your computer, use Content Advisor to block access to objectionable material, and specify how colors and fonts display on Web pages. You can also set your security level and specify what programs to use for e-mail and reading Internet newsgroups.

Open Internet Options in Control Panel.

Notes

  • Internet Options allows you to change the settings of Internet Explorer and cannot be used to change the settings of other Web browsers.
