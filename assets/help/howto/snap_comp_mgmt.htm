Using Computer Management

Computer Management helps you manage local or remote computers using a single, consolidated desktop tool. It combines several Windows 2000 administration utilities into a single console tree, providing easy access to a specific computer's administrative properties and tools.

Notes

  • To take full advantage of Computer Management, you must be a member of the Administrators group on the computer you are managing.
  • For information about using Computer Management, click the Action menu in Computer Management, and then click Help.
