Using the Internet Connection wizard

The Internet Connection wizard makes it easy to connect to the Internet. If you already have an account with an Internet service provider (ISP), the Internet Connection wizard collects all the necessary information from you and then creates the connection. If you do not have an account with an ISP, the Internet Connection wizard creates an Internet connection for you, and then lists ISPs and information about their services. To sign up for a new account, click an ISP in the list.

To open the Internet Connection wizard, double-click Connect to the Internet on the desktop.

Notes

  • Additional information on the Internet Connection wizard is available. If you are using Windows 2000 Professional, see the Windows 2000 Professional Getting Started online book. If you are using Windows 2000 Server, see Internet connections.
