Connecting to a remote computer or network

Network and Dial-up Connections provides connectivity between your computer and the Internet, a network, or another computer.

  1. Open Network and Dial-up Connections in Control Panel.
  2. In the Network and Dial-up Connections dialog box, double-click a connection.

Notes

  • If your computer is not on a network, you can still use Network and Dial-up Connections to gain access to shared information on a remote computer. To do this, your computer must have a modem, ISDN adapter, or other remote access device installed.
  • If you are connecting to your Local Area Network, the Local Area Connection connects automatically.
  • If you need to create a network connection, double-click Make New Connection in the Network and Dial-up Connections dialog box.
  • For information about using Network and Dial-up Connections, click the Help menu in Network and Dial-up Connections.
