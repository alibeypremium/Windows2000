Using Windows Report Tool

Windows Report Tool collects information about your computer that can be used by technical support personnel to diagnose and troubleshoot problems on your computer.

Open Windows Report Tool.

Notes

  • To open Windows Report Tool, click Start, click Run, and then type winrep.
  • If your technical support provider offers e-mail support, you can save the report as a text file on your computer and send it as an attachment in e-mail with your support request.
  • For information about using Windows Report Tool, click the Help menu in Windows Report Tool.
