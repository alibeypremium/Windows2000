Using Security Templates

Security Templates is a tool for creating and assigning security templates for one or more computers. A security template is a physical file representation of a security configuration, and can be applied to a local computer or imported to a Group Policy object in the Active Directory. When you import a security template to a Group Policy object, Group Policy processes the template and makes the corresponding changes to the members of that Group Policy object, which may be users or computers.

For information about Group Policy, opening a snap-in, or using the Microsoft Management Console (MMC), see Related Topics.
