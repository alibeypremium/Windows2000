Help with downloading

If you have an Internet connection, CD Player makes it easy to create playlists.

You can decide whether CD Player automatically downloads album information each time you insert a new CD (recommended for people on LANs with Internet connections), or whether CD Player prompts you before connecting to the Internet. If you rarely log onto the Internet, you can also save album information in a batch file, and download information for many albums at once. For more information on batching, see Related Topics.

If you select Always download new album information and then decide that you want to see this dialog box again, it's easy to get it back. Click Options, click Preferences, click the Album Options tab, and then select the Prompt me before attempting Internet download check box.
