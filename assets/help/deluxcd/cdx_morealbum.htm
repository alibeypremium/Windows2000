To search for additional artist and album information

  1. Click Internet, and point to Search the net.
  2. Click either Search for this artist or Search for this album.

    3. CD Player opens Internet Explorer to the default search engine which lists search results.

Notes

  • You must first enter album information or download it from the Web before you can use CD Player to search the Internet for additional information about the album and artist. For more information, see Related Topics.
  • To search the Internet, you must have an Internet connection. If your computer is not always connected, you may want to search for more than one album at a time. For more information, see Related Topics.
