To show pop-up descriptions for folder and desktop items

  1. Open Folder Options in Control Panel.
  2. Click the View tab.
  3. Select the Show pop-up description for folder and desktop items check box.

Notes

  •   Or, in Windows Explorer, click Tools, and then click Folder Options.
  • To apply folder settings only to the open folder, on the View tab, clear the Remember each folder's view settings check box.
