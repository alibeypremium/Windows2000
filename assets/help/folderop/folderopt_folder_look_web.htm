To make folders look like a Web page

  1. Open Folder Options in Control Panel.
  2. On the General tab, under Web View, click Enable Web content in folders.

Notes

  •   Or, in Windows Explorer, click Tools, and then click Folder Options.
  • When you use Web view, descriptive and hyperlink text appears on the left side of the folder window.
  • To turn off Web view in folders, click Use Windows classic folders.
