To associate a file extension with a file type

  1. Open Folder Options in Control Panel.
  2. Click the File Types tab.
  3. Click New.
  4. Type a new or existing file name extension, and then click Advanced.
  5. In File type, click New to create a new file type that is associated with the file name extension. Or, click one of the existing file types.

Notes

  •   Or, in Windows Explorer, click Tools, and then click Folder Options.
  • For information about how to make modifications to the file type, see Related Topics.
  • To change the program that opens a file, on the File Types tab, click Change.
