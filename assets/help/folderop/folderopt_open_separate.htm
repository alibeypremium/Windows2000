To open each folder in a separate part of memory

  1. Open Folder Options in Control Panel.
  2. Click the View tab.
  3. Select the Launch folder windows in a separate process check box.

Notes

  •   Or, in Windows Explorer, click Tools, and then click Folder Options.
  • When you open each folder window in a separate part of memory, the stability of Windows can be increased. However, your computer's performance might decrease slightly.
