To display hidden files and folders

  1. Open Folder Options in Control Panel.
  2. Click the View tab.
  3. Click Show hidden files and folders.

Notes

  •   Or, in Windows Explorer, click Tools, and then click Folder Options.
  • Hidden files and folders are dimmed in order to indicate that they are not typical items.
  • You can use Search to locate hidden files and folders without first displaying them if you know the name of the hidden file or folder. For information about using Search, see Related Topics.
  • If you want to see all file name extensions, clear the Hide file extensions for known file types check box.
